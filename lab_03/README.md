# Лабораторная работа № 3 - «Доска публикаций»

## Файлы

- `index.html` - разметка страницы
- `style.css` - оформление
- `app.js` - логика

## Запуск

1. Скачать/распаковать папку с проектом.
2. Открыть `index.html` в браузере.
3. Открыть DevTools (F12) -> вкладки Console и Network для наблюдения за запросами.

## Используемые эндпоинты

- GET  `https://jsonplaceholder.typicode.com/posts?_limit=5` - загрузка 5 публикаций
- POST `https://jsonplaceholder.typicode.com/posts` - создание публикации
  (тело: `{ "title", "body", "userId": 1 }`, заголовок `Content-Type: application/json`)

## Результаты проверки

| Проверка | Ожидаемый результат | Статус |
|---|---|---|
| Нажать «Загрузить публикации» | Появляются 5 карточек с заголовком и текстом, сообщение «Загружено публикаций: 5» | + |
| Пустые поля / одни пробелы -> «Создать публикацию» | Сообщение «Заполните заголовок и текст публикации.», запрос не отправляется | + |
| Корректные заголовок и текст -> «Создать публикацию» | POST -> HTTP 201, сообщение «Публикация создана: «…» (ID: 101)», карточка добавлена в начало списка, поля очищены | + |
| Временно `POSTS_URL = .../postz` (404) | Сообщение «Не удалось загрузить публикации: сервер вернул ошибку 404…», кнопка снова активна | + |
| DevTools -> Network -> Offline -> «Загрузить публикации» | Сообщение «…сетевая ошибка. Проверьте подключение к интернету.», кнопка снова активна | + |
| Во время запроса | Кнопка заблокирована, показывается «Загрузка…» / «Отправка…» | + |
